Variant C — Archive bin
Hide moves the action down into a collapsible Hidden section at the bottom — like an archive. Per-row "Hide" / "Restore" buttons; an undo toast appears for a few seconds. Mental model is spatial: visible up top, hidden in a bin below. Source (built-in / user) is shown as a pill on every row so the bin stays readable when it mixes both.
